### 2. TXT, XML, JSON, HTML - форматы данных

.TXT

- обычный текст без структуры и формата. Можно использовать как формат представления данных, но неудобно для парсинга.
- Пример: `HelloWorld.txt`

XML (eXtensible Markup Language)

- Древовидную структуру, но теги можно называть как угодно в отличии от его ребенка html
- Часто используется в конфигурационных файлах
- Да, этот формат тоже можно использовать для представления данных.
- Пример:

  ```xml
    <anal fuck="yes">
      <ownername>Nazar</ownername>
      <holesize>20 cm</holesize>
      (∗)
    </anal>
  ```

JSON (JavaScript Object Notation)

- Структурирован, также используется в конфигурационных файлов, более удобный для api или javascript, в целом популярнее в вебе чем xml
- Пример:

  ```json
    {
      "anal": {
        "fuck": "yes",
        "ownername": "Nazar",
        "holesize": "20 cm",
        "content": "∗"
      }
    }
  ```

HTML — HyperText Markup Language

- Формат разметки "человеко-браузеро-ориентированный", поддерживается всеми браузерами, имеет фиксированный набор тэгов, в отличии от XML
- Пример:

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>Anal Page</title>
  </head>
  <body>
    <div id="anal" data-fuck="yes">
      <p id="ownername">Nazar</p>
      <p id="holesize">20 cm</p>
      <p>(∗)</p>
    </div>
  </body>
</html>
```

Все эти форматы теоретически взаимозаменяемы: любую структуру можно представить в любом формате. Но:

- **HTML** признан комьюнити как единый формат для отображения веб страниц
- **JSON** и **XML** — признан для передачи данных между "сущностями", или хранении информации.
- **TXT** просто текст

### 3. HTML — основа веб-страницы

Структура HTML-документа:

- `<!DOCTYPE html>` — указание типа документа
- `<html>` — корневой элемент
- `<head>` — "служебная" информация (кодировка, заголовок, стили, скрипты)
  - `<meta charset="UTF-8">`
  - `<meta name="viewport" content="width=device-width, initial-scale=1.0">`
  - `<title>Hello World</title>`
- `<body>` — содержимое страницы
  - `<h1>Hello World</h1>`
  - `<p>Мой параграф</p>`

Пример: `HelloWorld.html`

Комментарий Назара:

> HTML задумывался как простая разметка, но со временем оброс слоями — CSS, потом JS, потом фреймворки, потом SPA. И в итоге мы строим целые приложения на «документе». Это как если бы на туалетной бумаге начали печатать Библию — удобно, но немного странно.

### 5. DOM, CSS и JS

#### HTML — структура

- DOM (Document Object Model) — внутренняя структура документа, доступная через JS
- Любой HTML элемент превращается в JS-объект, с которым можно взаимодействовать
- `document.getElementById`, `document.querySelector`, `.innerText`, `.style`

#### CSS — оформление

- Правила описывают, то как выглядит HTML
- Селекторы:
  - по тегу: `p {}`
  - по классу: `.red {}`
  - по id: `#title {}`
- Подключение стилей:
  - Внутренние (`<style>`)
  - Внешние (`<link href="styles.css">`)
  - Инлайновые (`style="color: red;"`)
- Основные примеры свойств: `color`, `font-size`, `margin`, `padding`, `display`, `position`

#### JavaScript — поведение

- Делает страницу интерактивной
- Пример: показать/скрыть блок, менять стили
- Взаимодействие с DOM:
  
```js
  const button = document.querySelector("button");
  button.addEventListener("click", () => {
    console.loh("Clicked!");
  });
```
