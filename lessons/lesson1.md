### 2. TXT, XML, JSON, HTML - форматы данных

**TXT**

- Неструктурированный текст. Подходит для человека, но неудобен для машины.
- Нет соглашений о форматировании - парсинг всегда кастомный.
- Пример: `HelloWorld.txt`

```txt
Hello World!
```

- Пример с массивом (будет восприниматься как строка "item1\nitem2\nitem3"):

```txt
item1
item2
item3
```

**XML** (eXtensible Markup Language)

- Древовидная структуру, но теги произвольны (в отличие от HTML)
- Часто используется в конфигурационных файлах, протоколах.
- Формат для хранения/передачи информации

```xml
  <anal fuck="yes">
    <ownername>Nazar</ownername>
    <holesize>20 cm</holesize>
    Big Foot
  </anal>
```

**JSON** (JavaScript Object Notation)

- Структурирован и компактен
- Используется повсеместно в API, для JS, хранении конфигурации и т.д.
- Формат для хранения/передачи информации

```json
  {
    "anal": {
      "fuck": "yes",
      "ownername": "Nazar",
      "holesize": "20 cm",
      "content": "Big Foot"
    }
  }
```

HTML — HyperText Markup Language

- Eщё один способ структурировать данные
- Формат разметки "человеко-браузеро-ориентированный", поддерживается всеми браузерами, имеет фиксированный набор тэгов, в отличии от XML. Валидность определяется спецификацией W3C.
- Используется для представления данных

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>Anal Page</title>
  </head>
  <body>
    <div id="anal" data-fuck="yes">
      <p id="ownername">Nazar</p>
      <p id="holesize">20 cm</p>
      Big Foot
    </div>
  </body>
</html>
```

Все эти форматы взаимно преобразуемы: любую структуру можно представить в любом формате. Но:

- **HTML** признан комьюнити(корпорациями) как единый формат для отображения веб страниц
- **JSON** и **XML** — признан для передачи структурированной информации или её хранения.
- **TXT** просто текст, неудобен для машин.

### 3. HTML — основа веб-страницы

Структура HTML-документа:

- `<!DOCTYPE html>` — это указание, что нужно следовать спецификации HTML5 и не пытаться поддерживать костыли из говна мамонтов
- `<html>` — корневой элемент
- `<head>` — "служебная" информация (кодировка, заголовок, стили, скрипты)
  - `<meta charset="UTF-8">`
  - `<meta name="viewport" content="width=device-width, initial-scale=1.0">`
  - `<title>Hello World</title>`
- `<body>` — содержимое страницы
  - `<h1>Hello World</h1>`
  - `<p>Мой параграф</p>`

Пример: `HelloWorld.html`

### 4. Почему простой язык разметки стал фундаментом фронтенда

HTML задумывался как простая разметка, но со временем оброс слоями — CSS, потом JS, потом фреймворки, потом SPA. И в итоге мы строим целые приложения на «документе». Это как если бы на туалетной бумаге начали печатать Библию при этом обмазавшись говном.

### 5. DOM, CSS и JS

#### DOM — структура

**База — это DOM**. Вся работа браузера крутится вокруг него.

DOM (Document Object Model) — это объектная модель документа. Когда браузер загружает HTML, он преобразует его в DOM-дерево.

- Каждый HTML-элемент — это **Node** (узел), который превращается в JS-объект и с которым можно взаимодействовать через JS.  
 - `document.getElementById`, `document.querySelector`, `.innerText`, `.style`

```html
<p id="example">Hello</p>
```

```js
const node = document.getElementById("example");
console.log(node.innerText); // Hello
```

#### CSS — оформление

- CSS — декларативный язык для описания внешнего вид DOM-нод, это просто способ массово задать свойства нодам, поддерживаемый всеми бразуерами.
- Есть альтернативные подходы к рендерингу (Canvas, SVG, WebGL), но все зависит от потребностей. CSS удобен своей каскадностью.
- Стилизация бывает через атрибуты (например, `fill="red"` в SVG) или через CSS — важно понимать разницу между DOM-свойствами и CSS-правилами.

Селекторы:

```css
p {}            /* по тегу */
.red {}         /* по классу */
#title {}       /* по id */
p > span {}     /* потомок */
p + div {}      /* сосед */
div:hover {}    /* псевдокласс */
div[data-x] {}  /* по атрибуту */
```

Подключение:

```html
<link href="style.css">         <!-- внешний -->
<style>p { color: red; }</style> <!-- внутренний -->
<p style="color: red;"></p>     <!-- инлайновый -->
```

#### JavaScript — поведение

JS делает страницу интерактивной.

- JS - язык программирования общего назначения и его задача позволять решать широкий спектр задач, в том числе изменение свойств DOM-нод.
- JS исполняется **после загрузки DOM**.  
  - либо ставь `<script>` внизу `<body>`,  
  - либо оборачивай в `DOMContentLoaded`.
- Работать с классами лучше через `.classList`, а не `className`.

```html
<button id="toggle">Показать</button>
<p id="text" style="display:none;">Привет!</p>

<script>
  const btn = document.getElementById("toggle");
  const text = document.getElementById("text");

  btn.addEventListener("click", () => {
    text.style.display = text.style.display === "none" ? "block" : "none";
  });
</script>
```
