### 2. TXT, XML, JSON, HTML - форматы данных

.TXT

- Обычный текст без структуры и формата. Можно использовать как формат представления данных, но неудобно для парсинга
- Можно положить любой формат данных, но нет соглашений, как это парсить. Обычно читают построчно
- Пример: `HelloWorld.txt`

```txt
Hello World!
```

- Пример с массивом:

```txt
item1
item2
item3
```

XML (eXtensible Markup Language)

- Древовидная структуру, но теги можно называть как угодно в отличии (в отличие от HTML)
- Часто используется в конфигурационных файлах
- Да, этот формат тоже можно использовать для представления данных.
- Пример:

```xml
  <anal fuck="yes">
    <ownername>Nazar</ownername>
    <holesize>20 cm</holesize>
    Big Foot
  </anal>
```

JSON (JavaScript Object Notation)

- Структурирован и компактен, также используется в конфигурационных файлов, более удобный для api или javascript, в целом популярнее в вебе чем xml
- Пример:

```json
  {
    "anal": {
      "fuck": "yes",
      "ownername": "Nazar",
      "holesize": "20 cm",
      "content": "Big Foot"
    }
  }
```

HTML — HyperText Markup Language

- Формат разметки "человеко-браузеро-ориентированный", поддерживается всеми браузерами, имеет фиксированный набор тэгов, в отличии от XML
- Используется для представления данных
- Пример:

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>Anal Page</title>
  </head>
  <body>
    <div id="anal" data-fuck="yes">
      <p id="ownername">Nazar</p>
      <p id="holesize">20 cm</p>
      Big Foot
    </div>
  </body>
</html>
```

Все эти форматы теоретически взаимозаменяемы: любую структуру можно представить в любом формате. Но:

- **HTML** признан комьюнити как единый формат для отображения веб страниц
- **JSON** и **XML** — признан для передачи структурированной информации или её хранения.
- **TXT** просто текст, неудобн для машин.

### 3. HTML — основа веб-страницы

Структура HTML-документа:

- `<!DOCTYPE html>` — это указание, что нужно следовать спецификации HTML5 и не пытаться поддерживать костыли из говна мамонтов
- `<html>` — корневой элемент
- `<head>` — "служебная" информация (кодировка, заголовок, стили, скрипты)
  - `<meta charset="UTF-8">`
  - `<meta name="viewport" content="width=device-width, initial-scale=1.0">`
  - `<title>Hello World</title>`
- `<body>` — содержимое страницы
  - `<h1>Hello World</h1>`
  - `<p>Мой параграф</p>`

Пример: `HelloWorld.html`

### 5. DOM, CSS и JS

#### DOM — структура

**База — это DOM**. Вся работа браузера крутится вокруг него.

- DOM (Document Object Model) — внутренняя структура HTML-страницы в виде дерева объектов.  
- Каждый HTML-элемент — это **Node**, который превращается в JS-объект и с которым можно взаимодействовать.  
 - `document.getElementById`, `document.querySelector`, `.innerText`, `.style`
- Существуют инструменты кроме JS, но JS — самый популярный способ.

```html
<p id="example">Hello</p>
```

```js
const node = document.getElementById("example");
console.log(node.innerText); // Hello
```

#### CSS — оформление

- CSS — это просто способ массово задать свойства DOM-нод.
- Есть альтернативные подходы к рендерингу (Canvas, SVG, WebGL), но все зависит от потребностей. CSS удобен своей каскадностью.

Селекторы:

```css
p {}        /* по тегу */
.red {}     /* по классу */
#title {}   /* по id */
```

Подключение:

```html
<!-- внутреннее -->
<style>p { color: red; }</style> 
<!-- внешнее -->
<link href="style.css">
<!-- инлайновое -->
<p style="color: red;"></p>
```

#### JavaScript — поведение

JS делает страницу интерактивной.

```html
<button id="toggle">Показать</button>
<p id="text" style="display:none;">Привет!</p>

<script>
  const btn = document.getElementById("toggle");
  const text = document.getElementById("text");

  btn.addEventListener("click", () => {
    text.style.display = text.style.display === "none" ? "block" : "none";
  });
</script>
```
