# Вступительный урок (HTML, Git, основы работы сайтов)

---

## Цель урока

Познакомить ученика с основами веб-разработки: понять, как работает сайт на базовом уровне, что такое HTML и зачем нужен Git. Настроить окружение, создать первую веб-страницу и опубликовать её в интернете.

---

## Темы

### 1. HTML — основа веб-страницы

Структура HTML-документа:

- `<!DOCTYPE html>`
- `<html>`, `<head>`, `<body>`
- Метаинформация в `<head>`, `<meta charset="UTF-8">`, `<meta name="viewport" ...>`

#### Собеседование - HTML

- Что такое DOM?
- Что такое семантические теги? Примеры: `<header>`, `<footer>`, `<main>`, `<article>`, `<section>`
- В чем отличие по сравнению с обычными тэгами. Почему важно использовать семантическую разметку?
- Что такое атрибут `lang` и как он влияет на доступность?
- Почему важно правильно структурировать HTML для screen reader'ов?
- `alt`, `aria-*` атрибуты.
- Какие теги влияют на SEO?
- Почему важно использовать правильные заголовки (`<h1>`, `<h2>`...)?
- Почему не стоит вставлять JS в `<body>`, если можно внизу или в `<head>` с defer?
- Почему не стоит вставлять inline css?

### 2. Как работают сайты

- Клиент-серверная модель
- Что такое запрос и ответ (request/response)
- Роль браузера в получении и отображении страниц
- Базовая схема: Пользователь → Браузер → Сервер → Ответ
- Что происходит при вводе URL в адресной строке

#### Собеседование - сайт

- Разница между HTTP и HTTPS
  - Что такое SSL-сертификат
  - Безопасность данных
- Что такое IP-адрес и DNS
- Что такое хостинг и домен

### 3. Инструменты разработчика

Sublime Text:

- Установка, настройка

DevTools в браузере:

- Инспекция HTML
- Просмотр структуры DOM

### 4. Git и GitHub

- Что такое система контроля версий
- Установка Git, базовая настройка (`git config`)
- Создание аккаунта на GitHub
- Основные команды Git:
  - `git init`, `git status`, `git add`, `git commit`, `git log`
  - `git remote add origin`, `git push`, `git pull`, `git fetch`
- Создание репозитория и привязка к проекту
- Заливка проекта на GitHub
- Публикация через GitHub Pages
  
#### Собеседование - GIT

- Что такое commit? Что он фиксирует?
- Что такое репозиторий?
- Что такое `origin`?
- Что такое `pull` и чем отличается от `fetch`?
- Что делать, если конфликт при слиянии?
- Что такое `.gitignore`?
