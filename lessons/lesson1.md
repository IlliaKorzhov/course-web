### 2. TXT, XML, JSON, HTML - форматы данных

.TXT

- обычный текст без структуры. Можно использовать для хранения данных, но неудобно для парсинга.
- Пример: `HelloWorld.txt`

XML (eXtensible Markup Language)

- Имеет древовидную структуру, но теги можно называть как угодно в отличии от его ребенка html
- Часто используется в конфигурационных файлах
- Нет валидности структуры и тэгов и единого формата
- Пример:

  ```xml
    <anal fuck="yes">
      <ownername>Nazar</ownername>
      <holesize>20 cm</holesize>
      (∗)
    </anal>
  ```

JSON (JavaScript Object Notation)

- Структурирован, также используется в конфигурационных файлов, более удобный для api или javascript
- Пример:

  ```json
    {
      "anal": {
        "fuck": "yes",
        "ownername": "Nazar",
        "holesize": "20 cm",
        "content": "∗"
      }
    }
  ```

HTML — HyperText Markup Language

- Формат "человеко-ориентированный", поддерживается всеми браузерами, имеет зарезервированный тэги, в отличии от XML
- Пример:

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>Anal Page</title>
  </head>
  <body>
    <div id="anal" data-fuck="yes">
      <p id="ownername">Nazar</p>
      <p id="holesize">20 cm</p>
      <p>(∗)</p>
    </div>
  </body>
</html>
```

Все эти форматы теоретически взаимозаменяемы: любую структуру можно представить в любом формате. Но:

- **HTML** признан комьюнити как единый формат для отображения веб страниц
- **JSON** и **XML** — признан для передачи данных между "сущностями", или хранении информации.
- **TXT** просто текст

### 3. HTML — основа веб-страницы

Структура HTML-документа:

- `<!DOCTYPE html>` — указание типа документа
- `<html>` — корневой элемент
- `<head>` — "служебная" информация (кодировка, заголовок, стили, скрипты)
  - `<meta charset="UTF-8">`
  - `<meta name="viewport" content="width=device-width, initial-scale=1.0">`
  - `<title>Hello World</title>`
- `<body>` — содержимое страницы
  - `<h1>Hello World</h1>`
  - `<p>Мой параграф</p>`

Пример: `HelloWorld.html`
